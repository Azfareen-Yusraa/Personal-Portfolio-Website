# 🌐 Personal Portfolio Website

A modern and responsive personal portfolio website built using **HTML**, **CSS**, and **JavaScript** to showcase my skills, education, projects, certifications, and contact information.

---

## 📌 Project Overview

This portfolio serves as my personal website where I present my technical skills, academic background, and software development projects. The website is designed with a clean and responsive interface to provide a professional online presence.

---

## ✨ Features

- Responsive Navigation Bar
- Professional Hero Section
- About Me Section
- Education Section
- Skills Section
- Certifications
- Project Showcase
- Contact Form
- Responsive Design
- Modern UI
