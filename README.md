# Personal Portfolio Website

A modern, responsive personal portfolio website built using HTML, CSS, and JavaScript to showcase my education, technical skills, projects, certifications, and contact information.

## Live Demo

https://azfareen-yusraa.github.io/Personal-Portfolio-Website/

## Features

- Responsive design for desktop, tablet, and mobile
- Modern hero section with profile image
- About Me section
- Education section
- Skills section
- Experience section
- Projects with GitHub and Live Demo links
- Certifications section
- Contact section
- Fixed navigation bar
- Mobile hamburger menu
- Smooth scrolling
- Active navigation highlighting
- Scroll reveal animations
- Typing animation
- Resume download

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages
